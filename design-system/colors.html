Color Palette

Every color has a job. Primary colors anchor every page. Secondary colors rotate — one per page/application, never combined. Peony is delight-only and never a base/structural color.

Primary — use most often

Warm Ivory
#F8F6F0
Foundation. Backgrounds, whitespace, breathing room.
Heritage Navy
#1D3557
Anchor. Headlines, wordmark, primary text, trust.

Secondary — rotate, one per page

Use one per application — not all three together. Choose based on context, not habit.

Sage
#94B4A9
Soft, calming. Wellness- and garden-adjacent content. Used on: About, Partners.
Emerald
#40826D
Depth, richness. Elevated/editorial moments. Used on: Work With Me, Tools, UGC, Consultation Intake.
Hydrangea Blue
#6F96CF
Personality, warmth. Social/community content. Used on: Home, Events, Newsletter, Worth Quiz.

Accent — reserved

Peony

Delight only. Sparingly — never as a base color. Used for: "Why this is personal" eyebrow moments only.
